# NAMES.md -- the word registry.  One word | one canonical definition | one file.
#
# Every load-bearing word the project uses gets one line here, the moment it is first
# used: the word, the one definition it carries, and the file where that definition is
# exhibited.  names.py walks the project and prints every definitional line for each
# registered word, grouped by sense; a word with more than one sense-group is a row.
#
# A word that cannot be restated in the terms of this registry is a finding -- a word is
# missing from the registry -- and it is added here, not argued.
#
